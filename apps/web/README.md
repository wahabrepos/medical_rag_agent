# apps/web

Next.js UI for the MedRAG agent, exported as static files. See the root README ("Web UI") for
what it shows and why.

```bash
corepack enable && pnpm install
cp .env.example .env.local          # NEXT_PUBLIC_API_URL=mock or the API's URL
pnpm dev                            # http://localhost:3000
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

- `src/lib/api.ts`: API client (streams `/v1/ask/stream` with fetch) and the demo-mode client
- `src/lib/types.ts`: the API's JSON, mirroring `apps/api/src/medrag_api/schemas.py`
- `src/mocks/fixtures.json`: recorded answers, generated by `eval/scripts/export_ui_fixtures.py`
- `src/components/`: form, progress, answer, statements, sources, feedback, settings

The API key (when the API needs one) is entered in Settings and kept in the browser's local
storage. Install scripts of dependencies are off (pnpm `allowBuilds`).
